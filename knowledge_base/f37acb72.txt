This Webinar Explains How to Close the Gap  The Hacker News  Nov 24, 2026 Supply Chain Security / DevSecOps Pinning GitHub Actions to an exact version of their code, known as SHA pinning, has become the go-to defense against software supply chain attacks. Attackers have already found a way around it. In March 2026, the hackers who hijacked Trivy, a widely used open-source security scanner, planted malicious code that looked like it came from GitHub's official checkout tool. They even labeled it a security fix. Teams pinned to it would have passed every check. The trick works because GitHub lets copies of a project, called forks, share code with the original.
