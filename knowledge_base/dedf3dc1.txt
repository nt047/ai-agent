Follow Us On Social Media       RSS Feeds  Email Alerts Hackers Infect 953 Online Stores With Scanner-Evading JavaScript, Mostly on Magento  Ravie Lakshmanan  Oct 26, 2026 Malware / Web Security An unknown threat actor has infected 953 online stores, most of them running Magento, as part of a long-running campaign active since July 2025. According to Dutch e-commerce security company Sansec, the activity is designed to add a small piece of code to the store's pages that, when visited by unsuspecting users, serves malicious JavaScript loader code through Magento CMS blocks. "When you visit, that code makes your browser ask the group's server what to do next," Sansec said . "The server first checks whether you are a real shopper or a security scanner, so scanners get nothing."
