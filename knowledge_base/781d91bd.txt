Follow Us On Social Media       RSS Feeds  Email Alerts Hackers Hide Linux Backdoor in Control Web Panel Server to Execute Commands Without Logs  Swati Khandelwal  Nov 06, 2026 Malware / Web Security A backdoor has been found hiding in the web server that runs Control Web Panel (CWP), a free panel for managing Linux hosting servers, researchers at QiAnXin's XLab said this week. The backdoored web server executes commands that attackers send via web requests, and those requests never appear in its access logs. Installing it takes root access, so the attackers must already control the server. The researchers, who named the backdoor cwpdoor , captured its installer, a shell script posing as a version update, on June 29. The installer handles only two versions of that web server, cwpsrv 1.15.10 and 1.24.0. The researchers do not yet know how attackers get the root access the installer needs.
