Follow Us On Social Media       RSS Feeds  Email Alerts Unpatched Cacti Zero-Day Enables RCE in Just Four HTTP Requests via Guest Access  Ravie Lakshmanan  Nov 27, 2026 Zero-Day / Vulnerability Details have emerged about a new zero-day vulnerability in Cacti , an open-source network monitoring tool, that could be exploited to achieve remote code execution. The proof-of-concept (PoC) exploit, which has yet to be assigned a CVE identifier, has been tracked as 4HTTP2SHELL and 4HTTP2ROOT . "I found a path from a fresh, unauthenticated HTTP session to command execution as the Cacti server user in four requests," a security researcher who goes by the online alias "ek0ms savi0r" said . "No login. No valid API key. No phishing. Just four HTTP requests against the default guest surface." The shortcoming affects Cacti Core 1.2.31, the latest version , when the guest account is enabled. It's worth noting that the guest account is disabled by default starting with Cacti version 0.8.
