Possible Vulnerability in Apple’s Automatic Reboot
<p>404Media is <a href="https://www.404media.co/cops-can-bypass-iphone-automatic-inactivity-reboot-graykey/">reporting</a> (alternate <a href="https://archive.ph/4qncQ">link</a>) that a cyber-weapons arms manufacturer is exploiting a vulnerability in iOS to bypass its automatic reboot security feature. This is the feature that automatically puts an iPhone into a more secure state if it hasn&#8217;t been used for 72 hours.</p>
