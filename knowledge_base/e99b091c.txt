Follow Us On Social Media       RSS Feeds  Email Alerts TeamViewer Flaw Lets Remote Computers Attack Users Who Connect to Control Them  Swati Khandelwal  Oct 30, 2026 Vulnerability / Endpoint Security TeamViewer has fixed a flaw that lets the machine being controlled in a remote session attack the computer that connected to control it. In a TeamViewer session, the computer that connects and takes control is the viewer, and the machine it controls is the host. A malicious or compromised host can exploit the flaw to crash the viewer's TeamViewer and, depending on the platform, may also run code on the viewer's computer. This works only after the user starts a remote-control session to that host. The fix is in TeamViewer version 15.83. The flaw is tracked as CVE-2026-111585 and scored 8.8 out of 10, in the high range.
