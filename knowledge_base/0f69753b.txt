Follow Us On Social Media       RSS Feeds  Email Alerts cPGuard Update Channel Hijacked to Backdoor Linux Servers and Collect Password Hashes  Swati Khandelwal  Nov 03, 2026 Web Security / Cyber Attack An attacker broke into the update system of the cPGuard security tool on November 2 and used it to send a malicious script to customers' Linux servers. The script installed a backdoor and collected password hashes and other sensitive files from servers that ran it, cPGuard maker OPSSHIELD said in an advisory . The attacker has since taken some of that data. cPGuard 5.88.25 and later versions remove the backdoor and the files the script left. Credentials the script copied may still work after the update, so any server that may have run the script also needs new passwords and keys. At 02:06 UTC, the attacker, who has not been identified, used compromised credentials to get into cPGuard's update system. The script went out in cPGuard versions 5.88.12 through 5.88.19.
