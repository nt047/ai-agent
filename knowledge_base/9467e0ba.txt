Follow Us On Social Media       RSS Feeds  Email Alerts Two Critical Wasmtime Flaws Could Let Malicious WebAssembly Modules Escape Sandboxes  Swati Khandelwal  Oct 26, 2026 Vulnerability / Software Security Two critical flaws in Wasmtime , a WebAssembly runtime that can be built into other software, could allow a malicious WebAssembly module to escape the sandbox intended to contain it, the project's maintainers say. An attacker would first need a vulnerable Wasmtime build to compile a module they control, and one of the flaws affects only ARM64 systems. Fixed versions were released on October 19 and 20, and the maintainers have not reported any attacks. Wasmtime runs WebAssembly code outside web browsers. Both bugs are in Cranelift, the compiler it uses by default to turn WebAssembly into machine code.
