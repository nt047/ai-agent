Follow Us On Social Media       RSS Feeds  Email Alerts Critical Flaw in Python’s Popular Pillow Image Library Allows Code Execution via a Crafted Image  Swati Khandelwal  Oct 23, 2026 Vulnerability / Web Security Pillow , the most widely used image library for Python, can be made to run operating system commands on a server by specifying the name of a file it is told to open. The flaw, CVE-2026-112900 , is in the way Pillow handles EPS images, which it opens by passing the file's name to Ghostscript , a separate program it runs to turn the image into pixels, without checking the name first. Ghostscript can read a name chosen by an attacker as instructions rather than as a file, and point it to a second file that carries commands to run. Pillow's maintainers fixed it in version 13.0.0 , released on October 16.
