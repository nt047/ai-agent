Because the gateway stores API keys for every connected provider, executing commands on the gateway process grants the attacker access to those credentials. The stock Bifrost binary binds the management API to localhost by default, which limits exposure to the local machine. The official Docker image binds to 0.0.0.0, making the management API reachable from outside the container if the port is published.
