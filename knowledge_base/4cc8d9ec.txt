Follow Us On Social Media       RSS Feeds  Email Alerts Tailscale Patches SSH Flaws That Could Let Hacked Devices Gain Root Access on Other Servers  Swati Khandelwal  Oct 28, 2026 Vulnerability / Network Security Tailscale has released version 1.104.4 to fix flaws in its built-in SSH server that could let an attacker reach services and files on other servers that only the root user should be able to touch. The flaws are in how Tailscale SSH forwards network connections, a job the Tailscale background process carries out with root privileges. To use them, an attacker must already control a device that the network's access rules permit to open an SSH session to the target, with forwarding allowed in that rule. The flaws come from a report called Tailworm , published days before the fix by Erica Windisch of Cyberdione Labs, who tested released versions of the Tailscale client and the self-hosted headscale control server in a lab.
