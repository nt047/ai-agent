Follow Us On Social Media       RSS Feeds  Email Alerts curl Patches HTTP/2 Upload Flaw After PoC Demonstrates Client-Side Code Execution  Swati Khandelwal  Oct 14, 2026 Vulnerability / Web Security A flaw in how curl handles HTTP/2 uploads lets a malicious server receiving an upload corrupt the client's memory, and the researcher who reported it turned that into code execution on the uploading machine. The curl project fixed it on October 14 in curl 8.23.0 . Taking over a client needs exact knowledge of its build and memory layout, and curl expects a real attack to end in a crash instead. The flaw, a use-after-free tracked as CVE-2026-92392 , affects curl and libcurl 8.12.0 through 8.22.0, both the command-line tool and the library that many other programs use for transfers. curl rates it High on its own four-level scale, its first High-severity flaw since the SOCKS5 heap overflow of October 2023 . The project cut its release cycle by two weeks to ship the fix.
