Follow Us On Social Media       RSS Feeds  Email Alerts Critical Rails Flaw Lets Attackers Write Server Files via Crafted ImageMagick Uploads  Swati Khandelwal  Nov 04, 2026 Vulnerability / Web Security A critical flaw in Ruby on Rails could allow an unauthenticated attacker to write arbitrary files on an app's server by uploading a crafted file if the app processes uploads using ImageMagick . The Rails project disclosed the flaw in an advisory and fixed it in versions 8.1.4.1 and 8.0.5.2. The flaw is in Active Storage, the part of Rails that handles file uploads. Some apps store uploaded files using Active Storage's Disk service, which stores them on the server's disk. In those apps, an attacker could also read any file the app can read. Those files typically include the app's secret_key_base and its credentials for other systems, according to Rails.
