# وكيل ذكاء اصطناعي أمني

يتعلم تلقائيًا من مصادر أمنية عامة، ويجيب عن الأسئلة من Termux عبر GitHub Issues.

## الإعداد
1. أنشئ مستودعًا على GitHub.
2. أضف `HF_TOKEN` في أسرار المستودع.
3. استخدم الأوامر التالية من Termux:
   - للتعلم: `gh issue create --title "تعلم" --body "تعلم: <رابط أو نص>"`
   - للسؤال: `gh issue create --title "سؤال" --body "سؤال: <السؤال>"`
